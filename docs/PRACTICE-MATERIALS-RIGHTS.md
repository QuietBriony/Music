# 練習アプリの教材と権利（いまは遊ぶ用・売るならこう）

2026-11-17。本人の方針：「売るよりは、楽しく使う優先にしよう。売るなら、こう　って定義はしていいね。今は遊ぶの最優先」。

この文書には、練習PWA（`practice/`、v41）が使っている教材の出所と権利の棚卸しと、売る場合の条件の定義を書く。
販売の準備（初心者の試用・支払い・購入後サポート）は後回しにする。この文書のために公開版を変えることはしない。
公開版を変えるかどうかは、1章の「本人が決めること」から本人が選ぶ。

法律の助言ではない。売ると決めたときに、専門家や相手に確かめる項目の下ごしらえとして使う。調べた範囲と方法は10章に書く。

安里屋ゆんたの歌詞の注意：

- よく歌われる標準語の歌詞は、1934年の「新安里屋ユンタ」のもので、作詞は星克（1977年没）。日本では2047年末まで保護される（著作権法51条・57条）。内蔵しない。
- 竹富島に伝わる八重山言葉の歌詞は、もとは伝承の別の節で歌う。いまの内蔵譜（宮良長包の節）に合わせられるかは、先生の教材で確かめてから本人が決める。

ほかの注意：

- きらきら星の日本語の歌詞（武鹿悦子の訳詞）は保護期間中で、入れていない。入っているのは英語の歌詞だけ。
- 近現代の曲（島唄・涙そうそう・童神・三線の花・時代の流れ・あなたに、ギターの11曲）の歌詞・旋律の譜面・音源は入れていない。ギターの11曲には、コード名と時刻が入っている（4章）。
  遊ぶときの歌詞は「手元の歌詞」に自分で入れる（端末の中だけに保存し、送らない）。
- 新しく歌詞を入れるときは、曲ごとに本人の明示の許可を取り、AGENTS.mdの決まり3の例外と出所記録の両方に書く。決まり3は歌詞を原則repoに入れず、例外はAGENTS.mdに書いたものだけとしている。
  いまの4曲分は、本人の依頼の記録が出所記録（`practice/songs/lyrics-provenance.json`）にだけあり、AGENTS.mdの例外にはまだ載っていない（v42で載せた）。

## 3. YouTubeの動画

アプリは動画をYouTubeの埋め込みプレーヤー（`youtube-nocookie.com`）で再生する。操作に使うスクリプト（IFrame Player API）は`www.youtube.com`から読み込む。
どちらも本人がボタンを押したときだけで、動画を端末に保存しない。作者が埋め込みを止めた動画は、YouTubeへのリンクで開く。

|---|---|---|---|
| 三線の先生 | 11（埋め込み10、リンクだけ1） | 沖縄三線宮里道場＝宮里英克沖縄三線教室（8）、伊禮俊一（1）、松本克樹（2。通常レッスン1本はリンクだけ） | 工工四・歌詞付きの教材。区間・章ボタン・反復 |
| ギターの先生 | 15（埋め込み4、リンクだけ11） | JustinGuitar／JustinGuitar Songs（5）、Marty Music（3）、Plug+ by Rittor Music（2）、Jon MacLennan、Drue James、GuitarLessons365Song、Cole Johnstone、ギターで歌おうch（各1） | 埋め込むのは押さえ方の手元の動画4本（Plug+ 2、JustinGuitar 2）。曲の解説11本はリンクだけ |

記録だけで画面に出ないもの：Nikola Gugoski、Dave Doing Guitar（`practice/songs/jigsaw-study.json`の照合用）。

YouTubeの規約（いまも、売るときも）：

YouTubeのAPI利用規約とDeveloper Policiesは、売るかどうかに関係なく、埋め込みプレーヤーを使うだけでかかる。このアプリはIFrame Player APIを使っている。

- いまの公開版で足りないもの（直すかどうかは本人が決める）：
  - YouTube利用規約へのリンクと、使う人がそれに同意するという文（III.A.1）。
  - プライバシーポリシー（III.A.2）。いつでも見られる場所に置き、使い始める前に同意してもらう。
    中身は、YouTube API Servicesを使うこと、Googleプライバシーポリシーへのリンク、端末に保存するもの（練習位置・手元の歌詞・補正・設定・マイクを最後に使った時刻）とその使い方。
    動画を読み込むとYouTubeへ情報が送られ、cookieなどが使われること。MIDIのURLを入れると、その配信元へ端末から直接取りに行くこと。更新の確認で配信元へつなぐこと。
  - 埋め込む動画ごとに「子ども向け（Made for Kids）」の設定を調べ、子ども向けなら追跡を切る（III.E.4）。いまは調べていない。
  - プレーヤーは200×200px以上にし、上に何も重ねない（Required Minimum Functionality）。
    三線の先生の動画は、幅375pxの縦画面で約350×197px、横画面の譜面表示で約313×176pxになり、高さが少し足りない計算（実機では未確認）。ギターの動画は足りている。
  - 「コード図を大きく」で動画を隠しても、「押さえ替えで待つ」の途中なら、マイクの判定で隠れたまま再生が再開する経路がある。III.Iは、画面に出ていないプレーヤーで再生する機能を禁じているので、これに当たりうる。
- いまの作りで守っているもの：動画を保存・オフライン再生しない（III.E.1）。「押さえ替えで待つ」で止まっても、YouTubeの再生ボタンでいつでも続きを見られる。
  判定に使うのは自分の楽器の音だけで、YouTubeの音は取り込まない。
- まだ確かめていないもの：読み込みと最初の再生は本人のボタン操作で始まるが、再生の前に「動画を読み込む」を押す作りが、III.F.3の「再生ボタン以外の操作を求めない」に当たらないか。
  画面下の固定ボタンや更新の案内が、スクロールでプレーヤーに重ならないか（Required Minimum Functionality）。
- 歌詞が映る動画（歌詞・コード付きの演奏11本と、三線の先生の動画）は、歌詞の表示が許諾済みかどうか、アプリからは分からない。
  YouTubeの規約は、無料でも、権利を侵害する動画を使うことを禁じている（III.E.1、III.I）。先生や作者へ一言伝えるとき（7章の6）に合わせて確かめる。
  差し替えるかは本人が決める（替えると、その動画に合わせたコード列は合わせ直しになる）。

売るなら：

- 「埋め込んだYouTubeプレーヤーで見ることに料金を取らない」（III.F.3）。アプリを売ること自体は、ほかの条項（III.G.1の禁止事項、III.F.3）を守る前提で認められている（III.G.2）。
- 上の「いまの公開版で足りないもの」を全部そろえる。
- 三線の中心は宮里英克教室の8本。法律上の許可が要るとは限らないが、売る前に教室へ一言伝える（サイトに問い合わせページがある）。
  教室は初心者向けのテキスト（やさしく弾ける沖縄三線の基礎）と譜面集（沖縄三線譜面集vol.1）を販売しているので、教室の案内へつなぐ形がよい（本人判断）。

ChordUの利用規約（Terms of Use）：

- Liability：曲とコードの利用を「個人の非商用」に限り、個人利用以外の複製と、公開・送信・配布・公衆への表示・改変・二次的著作物の作成・販売を禁じている。サイトの下部にも「教育・個人の非商用に限る」とある。
- User guidelines：ボットなどによる自動の取得を、許可なしには禁じている。
- 11コースをどう取ったか（人が画面で見たか、道具でページを読んだか）の記録はない。出所記録にはページ内部の項目名がある。取り方を確かめて出所記録に書く。作り直すときも、ChordUのページを自動で読みに行かない。

いまの公開版での扱いは、次の3つから本人が選ぶ。

- (a) このまま遊ぶ。
- (b) 11コースを、自前で起こしたコード列に置き換える（Codexの作業）。歌詞・コード付き演奏の3曲は、動画に映るコード表示から起こす。
  公式チャンネルの8曲は動画にコード表示がないので、コード表示のある動画に替える（YouTubeの音を取り込んで起こすことはしない。本人に耳コピも求めない。8章）。
- (c) 11コースを外す。歌詞・コード付き演奏の3曲（Imagine、Woman、Could You Be Loved）は新しく使う人の最初の教材なので、外すとこの3曲の自動送りがなくなる。
  ほかの5曲はMunsonの起こしが残り、時間よ止まれ・Jigsaw・YES MY LOVEは影響を受けない。外しても公開repoの履歴には残る（強制pushは禁止）。

コード列は、コード名と秒数だけで、動画・音・歌詞・旋律の譜面は写していない。
コード名の並びや一般的な押さえ方は、一般に著作権の対象になりにくいとされる（判例などの一次資料は、ここでは確かめていない）。

## 8. 本人がほしい流れと、権利の分かれ目

2026-11-17 本人：「工工四　つくって、歌詞併記　が　三線はほしいやつ」
「ギターはコード練習　しながら　タブ譜　歌詞　みれたら、上記　三線　のほしいながれに近い感じかな？」「音で判定して、伴走する感じ？」

Claudeの読み：三線もギターも、譜面（三線は工工四、ギターはコード図とタブ）と歌詞を一つの画面に出し、弾いた音をアプリが端末の中で聞いて進む。
進み方には、合うまで待つ形と、止まらずに一緒に進んで合否だけ示す形がある。どちらが合うかは、遊んで確かめる。

その後の本人の確認と選択：

- 本人から「私が、なにか耳コピできなかんじでやるの？」と確認があった。本人に耳コピや譜面の打ち込みを求める案はとらない。

権利の分かれ目：

- アプリに入れて公開できるもの：伝承曲や保護期間の切れた曲で、自前で起こした工工四・タブと、伝承の歌詞。先生の譜面や配置、現代語訳、新しい編曲は写さない。
  例：てぃんさぐぬ花（CC BY-SAの条件つき）、月ぬ美しゃ、きらきら星の英語の歌詞。repoに歌詞を足すときは、曲ごとに本人の明示の許可を取り、AGENTS.mdの決まり3の例外と出所記録の両方に書く（2章）。
- どの曲でも：自前で起こしたコード名と時刻（ChordU由来は除く）、押さえ方、ストロークの型は、一般に著作権の対象になりにくいとされる。歌詞・旋律・リフは含めない。
- 公開版に入れないもの：近現代の曲（三線の6曲とギターの11曲）の旋律の工工四、リフや旋律のタブ、歌詞。きらきら星の日本語の歌詞。
- Claude・Codexは、近現代の曲の工工四や歌詞を、公開版の外でも代わりに作らない。著作権法30条が認めるのは、使う本人が自分のために写す場合。
  工工四に起こす（編曲する）のも、自分で使う範囲なら認められている（47条の6）。
  ただし、違法な配信と知りながらの録音・録画・ダウンロードや、コピー防止を外しての複製は除かれる（30条1項2〜4号）。
  自分のために作ったものを公開版や公開repoに入れると、目的外の使用として複製とみなされる（49条）。
- 動画の曲で「弾いた和音で進む」ときも、待つのは本人が選んだときだけにし、YouTubeの再生ボタンでいつでも続きを見られるようにする（III.F.3）。
  判定に使うのは自分の楽器の音だけにし、YouTubeの音を取り込んで解析・保存しない（III.E.1、III.I）。動画を見たことに点数やごほうびを付けない（III.F.3）。
