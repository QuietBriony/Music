# Lyric Lab の使い方

[Lyric Labを開く](https://music-stack.pages.dev/lyric-lab.html#shelf)。普段は[Listen](https://music-stack.pages.dev/listen.html)からも開けます。

## 詩を読む・ひとこと足す

最初の画面に詩と断片が並びます。題を押すと本文を読めます。
本文の下の「ひとこと足す」に、言い直し・引っかかった行・浮かんだ音を書き、
「追記を残す」を押します。本文はそのままで、追記が下に積まれます。

新しい言葉は「＋ 言葉を置く」から。題はなくても大丈夫です。
本文を書いて「この版を保存」を押すと一覧に残ります。

## 本文を磨く

「本文を磨く」で書き換え、「この版を保存」。以前の本文は
「原文・これまでの版」で読めます。「別案をつくる」は現在の本文を複製します。
原作を残して、別の方向に育てられます。

書きかけはこのブラウザに保持され、開き直すと「書きかけを続ける」から戻れます。
保存済みの本文とは別です。ブラウザの保存容量が足りない場合は失敗を表示します。
閉じる前に「端末をつなぐ・バックアップ」から全作品をバックアップしてください。

## 前の詩が見えないとき

「端末をつなぐ・バックアップ」を開きます。接続済みの端末で
「同期キーをコピー」し、同じキーを新しい端末に貼り付けて「接続して詩を読む」。
キーは作品へのアクセスを持つので、公開リンクや公開リポジトリには置きません。
キーが手元になければ、接続済み端末または既存の管理用保管場所から確認します。

画面上部に「この端末に保存済み・クラウド未同期」か「保存済み」が出ます。
接続中は保存操作の後、変更した作品だけをクラウドにも送ります。
失敗した分は端末に残り、一覧の「未同期を送る」で再試行できます。
別の端末の新しい版がある場合は上書きせず止めます。その作品を開き、
「こちらを別案として残す」で両方を残せます。

以前の詩を読み込めていない状態は、作品がゼロという意味ではありません。
GitHub Pages版は端末保存のみです。端末間で使うときは上のCloudflare版を開いてください。

## 音につなぐ

「声と音のメモ」に、息継ぎや速さ、鳴らしたい音を書きます。
ボイスメモやBandLabなどで録った音は、共有可能なリンクを添えられます。
このアプリ自体には録音機能・音声ファイルのアップロード機能はありません。

「素材・AIへの相談・曲にする設定」は必要なときだけ開きます。
「AIに相談する文をコピー」で本文と追記を持ち出し、自分でAIへ貼り付けます。
「素材から下書きを試す」は端末内のルールによる組み立てです。
保存中の本文は置き換えず、採用するときは別作品にできます。

バックアップには本文・追記・履歴・書きかけが入り、同期キーは入りません。
読み込むと既存作品を上書きせず、別作品として追加します。
