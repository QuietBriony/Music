# HAZAMA — Lyrics & Session Notes

**ユニット**: HAZAMA（間）。AI × 人のユニット。AI がトラックと言葉を作り（Rick Smith 側）、人が声を置く（Karl Hyde 側）。

**Track 01**: Still Moving — 128 BPM / A minor / 約6分 / hypnotic dub-techno。

**歌唱方針**: メロディは歌わない。呟く・繰り返す・通り過ぎる。感情を込めない。街ですれ違った誰かの独り言が一瞬だけ聞こえた、その温度で。英語と日本語を同じ調子で言う（切り替えを意識しない）。声量は小さくていい。マイクが近ければ届く。

**重ね録りはしない**: 声は1本でいい。ディレイが2人目と3人目をやってくれる。言った後の「尾」を聴いて、それに被せない。

**録音手順**: band-room を `?band=hazama` で開く（`🎛 AI 再現` が自動選択される）→ START → `⏺ live record` の **live mic** を ON（要ヘッドホン）→ **● REC** を押す → 声＋バンドが1本にバウンスされる。ワンテイクで通す。言い間違い・タイミングのズレは録り直さなくていい（それもテクスチャ）。ダメなら止めて、もう一回最初から。

**時間の目安**: 16小節 ≈ 30秒、32小節 ≈ 60秒。

## 構成リファレンス（実装済み・実際にこう鳴る）

| section | 小節 | 音 |
|---|---|---|
| intro | 16 | 沈んだキック＋サブパルス。arp/bass なし |
| arp | 16 | 16分アルペジオのリフ登場、bass 入場 |
| drive | 16 | 4つ打ち＋裏拍オープンハット。arp はコール&レスポンス |
| verse | 32 | arp が休符で抜けディレイが答える。転がるベース |
| lift | 16 | arp が mantra のリフへ変容。パッドが開く |
| mantra | 32 | 全部乗る。arp が上のオクターブで開く（第1のピーク） |
| break | 16 | **ベースが完全に落ちる**。ハーフタイムのキック＋ダブのハット＋パッド |
| release | 32 | 全部が叩き込まれる（最大の山） |
| outro | 16 | フィルターが下がりキックがフェード。arp だけ残る |

## 参考: Underworld DNA

- Rick Smith: 8〜16小節ループがゆっくり変異する long-form。解決を焦らない。
- Karl Hyde: ノートに拾った言葉のカットアップ。二人称・列挙・反復・現在形・脱力。

## 01 Still Moving

[intro]

（16小節 歌わない。静かに呼吸。ここでマイクとの距離を決めておく）

[arp]

（前半8小節は待つ。リフが揃ってから、置くように一度だけ）

夜が線になる

（4小節あけて、同じ温度でもう一度）

夜が線になる

[drive]

（4小節待つ。あとはアルペジオとの会話。1行言ったら黙って、答えを聴く）

hold the wheel, don't hold your breath

眠らない街、眠らないまま

windows down, radio off

[verse]

（32小節。間が主役。1行ごとにディレイの返事を待ってから次へ）

neon on the glass, neon on your face

光が通り過ぎる、名前もなく

58号、誰もいない

（ここで8小節 黙る）

誰かの声がまだ残ってる
もう一回、もう一回、って言った

間に落ちて、そのまま流れる

（残りは黙る。lift を待つ）

[lift]

（パッドが開く。声は低いまま、hook の部品を先に見せる）

here it comes, here it comes

（4小節あけて）

still moving…

lights go by

[mantra]

（32小節。低く、均一に、マイクの近くで。祈りではなく計器の読み上げ）

still moving, still moving, lights go by
still moving, still moving, don't ask why

（×4、前半16小節）

still moving, still moving, lights go by
still moving, still moving, don't ask why

（×4。少しだけ口を開く。最後の "don't ask why" だけ囁きに落とす）

[break]

（ベースが消える。マイクに一番近づく。全部囁き。1行ごとに尾が消えるまで待つ）

間に落ちる、落ちる、落ちていく

falling in the space between

声だけ残して

（言い終えたら無音。ディレイの尾だけを release へ渡す）

[release]

（最大の山。ここだけ声を開く。ディレイと一緒に歌う）

still moving, still moving, lights go by
still moving, still moving, so am I

（×2、8小節）

もう一回、もう一回

still moving, still moving, 止まらない
still moving, still moving, 止まらない

still moving, still moving, lights go by
still moving, still moving, so am I

（×2。言い切ったら残り4小節はバンドに任せる）

[outro]

（キックが沈んでいく。独り言に戻る）

still moving…

まだ、動いてる

（あとはアルペジオだけ。息の音で終わっていい）
