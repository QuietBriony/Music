# BL-053 練習PWA：YouTube の規約が求める表示を入れる（Codex 用の依頼文）

2026-11-19 に Claude が書いた依頼文。worker（`worker-gaming`）の Codex アプリにある練習PWAのスレッド
「ギターと三味線の練習PWA検討」で使う。この文書だけでは本人の承認にならない。本人がスレッドに書いた言葉を承認として扱う。

## 本人の決定（原文）

Claude が「練習アプリの YouTube 規約対応（規約へのリンクとプライバシーポリシー）を、次の版で入れるか」と聞き、本人が「４　入れる」と答えた（2026-11-19）。

根拠は `docs/PRACTICE-MATERIALS-RIGHTS.md` の1章「本人が決めること」の1と3章。
YouTube の API 利用規約と Developer Policies は、売るかどうかに関係なく、埋め込みプレーヤー（IFrame Player API、`practice/youtube.mjs`）を使うだけでかかる。
いまの公開版には、YouTube 利用規約へのリンクも、プライバシーポリシーもない。

## やること（次の版で）

1. **利用規約のページ**（短くてよい）を `practice/` の中に置く。
   - YouTube 利用規約（https://www.youtube.com/t/terms ）へのリンクを置き、「このアプリで YouTube の動画を見ると、YouTube 利用規約に同意したことになる」と書く（III.A.1）。
2. **プライバシーポリシーのページ**を `practice/` の中に置く（III.A.2）。
   - アプリのどの画面からも、いつでも開ける場所（設定や情報の窓など）にリンクを置く。
   - 使い始める前に同意してもらう。初めて開いたとき（または、この版へ更新して最初に開いたとき）に、一度だけ「同意して使う」を出し、端末に覚える。同意しない場合の動き（YouTube の動画を読み込まない等）も決めて書く。
   - 書く中身（事実だけ、平易な日本語で）：
     - このアプリは YouTube API Services（埋め込みプレーヤー）を使うこと。Google プライバシーポリシー（https://www.google.com/policies/privacy ）へのリンク。
     - 端末のブラウザ保存（localStorage）に置くもの：練習位置、手元の歌詞、コードと時刻の補正、設定、マイクを最後に使った時刻など（実際のキーを確かめて書く）。これらは送らない。
     - マイクの音は端末の中で判定し、録音も送信もしないこと。
     - YouTube の動画を読み込むと、YouTube（Google）へ利用者の情報が送られ、cookie などが使われることがある。再生枠は `youtube-nocookie.com`、操作用のスクリプトは `www.youtube.com` から読み込むこと。
     - 自分の MIDI の URL を入れると、端末からその配信元へ直接取りに行くこと。
     - 更新の確認で、配信元（Cloudflare Pages・GitHub Pages）へつなぐこと。
     - 利用状況の計測：repo には計測のスクリプトはない。配信された HTML に Cloudflare Web Analytics などの計測が足されていないかを、公開版で確かめてから書く。
3. **あわせて直す（3章の、いまの公開版で足りないもの）**
   - 埋め込む動画ごとに「子ども向け（Made for Kids）」の設定を確かめ、出所記録に書く。子ども向けの動画があれば、追跡を切る扱いにする（III.E.4）。確かめる手段が無ければ、そのことを記録する。
   - 三線の先生の動画のプレーヤーを、どの画面でも 200×200px 以上にする（Required Minimum Functionality。幅375px の縦画面と、横画面の譜面表示で足りない計算）。
   - 「コード図を大きく」で動画を隠している間は、「押さえ替えで待つ」のマイク判定で再生を再開しない（III.I：画面に出ていないプレーヤーでの再生）。
   - 固定のボタンや更新の案内が、スクロールでプレーヤーの上に重ならないことを確かめる。
4. 文書：アプリ内の「利用条件」と、v41 以前から残る「今回できること」などの説明が古ければ、合わせて直す。

- 法律の助言のように言い切らない。書くのは、このアプリが実際にしていることだけ。
