## A. 操作の不具合（優先）

1. **一行反復が、手動の歌詞になると消える。収録歌詞の写しが端末に残る。**
   - `practice/score-lyrics.mjs:19` は `follow===false` のとき反復の範囲を返さないので、全画面の「この行を反復」が2つとも消える。
   - v43 から、歌詞の行一覧で行を選ぶだけで `persist()` が呼ばれ（`practice/lyrics.mjs:139`）、手動の状態と、収録歌詞の本文・読みの写しが保存される。「前の行／次の行」（`:136`）と「収録歌詞に戻す」（`:134`）も同じ写しを保存する。
   - そのため、赤田首里殿内・谷茶前節で「次の行」を1回押すと写しが残る。開き直すとクレジットが「…この端末の保存内容」になり、あとで収録歌詞を直しても、その端末には届かない（権利の都合で外す場合も届かない）。
   - 直し方：本文・読みが収録版と同じなら、位置（`manualLine`・`follow`）だけを保存し、本文・読みは保存しない。「この端末の保存内容」は、中身が収録版と違うときだけ表示する。保存済みの写しが収録版と同じなら、いまの収録版を使う。反復の範囲は「時刻が本人のものか」で判断し、`follow` には頼らない。
   - 全画面にも「譜面への追従に戻す」を出す（任意）。
   - 回帰検査：行を選んだあとも、収録歌詞の反復範囲が残ること。写しが収録版と同じなら、開き直したあと新しい収録版が出ること。
2. **安波節の2行目の反復に、間奏が入る。**
   - `practice/score-lyrics.mjs:26` は、行の終わりを次の行の始まりにしている。安波節（`practice/folk-lyrics.mjs:14` の拍 8/28/61/81）では、2行目に歌わない18拍（約13秒、2巡目の前奏を含む）が入る。
   - 直し方：各行を、その行の最後の音節の音で終える（プリセットに行ごとの終わりを持たせてもよい）。前奏の間は、反復ボタンを隠すか表示を変える。
   - 回帰検査：内蔵のどの行でも、反復の末尾の歌わない部分が3拍以内であること。
3. **横向きの電話で、反復ボタンが2つとも隠れる。**
   - 三線の全画面は既定で集中表示になる（`practice/full-score.mjs:129`）。1つ目のボタンは集中表示で隠れる `.sheet-options` の中にあり（`practice/full-score.css:59`）、2つ目は高さ500px以下の横向きで隠れる `#full-score-lyrics` の中にある（`:69`。`:79` の規則は優先度が低く効かない）。
   - 直し方：横向きの操作列（`.sheet-buttons`）か見出しに、小さい反復ボタンを置く。
4. 小さい点（できる範囲で）：
   - 歌詞のある曲では、全画面のマスの高さが増え、横向きの短い画面で縦にスクロールが出る（`practice/full-score.mjs:48-50`）。読みやすさとの兼ね合いで決める。
   - 新しい端末では、歌詞の欄の読み方・意味が隠れている（`practice/lyrics.mjs:64` の既定が「歌詞だけ」）。読み方と意味がある曲は、既定を「読み方つき」にする。
   - 電話では、先生の動画の窓の「次の行」が画面の下に隠れる。手動で進める曲には、前の行／次の行の固定バーを置く。
   - 「今回できること」（`practice/index.html:138`）と、情報の窓の版の説明（`:185`）が v41／v40 のまま。v44 の内容に直す。

## B. 出典の記録（権利）

1. **安波節**
   - 内蔵の譜（`scripts/build-practice-aha.mjs:8` の53マス）と歌詞の位置は、mabui.jp の工工四（PDF、sha256 `59e50cd7…`）のマスの並びどおり。
   - mabui の工工四は、川田松夫『琉球音楽歌三線箏曲総譜』（琉球文化守礼会、1965）をもとに記号を一部簡略化したもの（mabui の「工工四について」のページ）。川田（1981年没）が独自に加えた部分は、日本では2051年末まで保護される。
   - いまの記録は「New symbolic entry」「先生の譜と照合」とし、mabui を照合用の資料扱いにしている。出典欄も3通りある（`practice/songs/aha-provenance.json:5` は ks-sanshin、`:20` は mabui の PDF、`practice/scores.mjs:13` は mabui のページ）。
   - 直し方：記録（`aha-provenance.json`・`practice/songs/provenance.json`・`build-practice-aha.mjs` の注記・`lyrics-provenance.json`）に、マスの並びと歌詞の位置が mabui の譜（元は川田1965）によることを書く。使ったのは古典の大きい譜字だけで、川田の記号やレイアウトは使っていないことを、1993年の琉球大学の論文の野村流の譜（同じ系統）とできる範囲で照らして書く。出典欄をそろえる。
   - 歌詞の本文は、先生の教室のブログ（ks-sanshin）からではなく、古典の公開資料（mabui の本文や論文）を出典にする。読みは ks-sanshin と同じなので、「独自の読み」ではなく「ks-sanshin の読みによる」と書く。
   - アプリの全画面のクレジットの「原譜・出所 ↗」（`practice/app.mjs:707`）が mabui を指していて、記録と食い違う。記録に合わせた表示にする（例：「照合した教材 ↗」）。
   - 表示の分類：安波節は古典曲として扱われ、安波の村に伝わる元の歌（原歌）は別の歌詞。アプリの「沖縄民謡」「国頭村安波の伝承歌」という表示を、古典の安波節に直す。
2. **谷茶前節の囃子**：囃子の2行（`practice/folk-lyrics.mjs:43`）は、挙げた出典のうち琉球村（ryukyumura.co.jp の oki100 vol5）だけに載っている。国立劇場おきなわの歌詞PDF（sha256 `86f84b76…`）にも、伊禮俊一のブログにも無く、教育芸術社のものは形と位置が違う。「確認した囃子」と書かず、そのとおりに `folk-v43-provenance.json`・`lyrics-provenance.json`・クレジットに書く。
3. **赤田首里殿内**：照合に挙げた文化庁事業の PDF（kodomogeijutsu.go.jp の f80.pdf）が 404 で開けない（2026-11-17）。いま開ける公開資料（琉球村 vol1 など）に差し替えるか、開けないことを日付つきで記録し、アプリのクレジット（`practice/folk-lyrics.mjs:39`）から外す。
4. 記録のつながり：

5. 小さい点：

## 守ること

- 歌詞の本文を新しく足さない。直すのは記録と表示と、上の言い換えだけ。外す場合は外してよい。
- 近現代の曲の歌詞・旋律の譜面は、どこにも書かない。先生の教材は照合にだけ使い、画像・レイアウト・独自の表記は写さない。
- 練習位置・手元の歌詞（本人が実際に編集したもの）・調弦・感度・しおりの保存は保つ。本人が編集した歌詞は消さない。
