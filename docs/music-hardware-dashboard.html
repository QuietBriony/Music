Authority boundary

Public workflow, private operational truth

Music は再利用可能な workflow と安全ルールを正本にする。所有機材、実配置、hostname、exact wiring、driver snapshot、検証済み設定は、利用可能なら private operator overlay を先に読む。private source がない環境では推測せず needs_verification にする。

USB audio out

EP-133 → host

現行公式 guide は class-compliant USB audio output を説明している。DAW input endpoint として実機確認する。

USB audio in

host → EP-133

host output を EP-133 に送り、sample 時は USB source を選ぶ。実際の sample write は人間 gate。

USB MIDI

notes / clock / control

MIDI は audio ではない。方向、mapping、transport action を明示し、record や device write を自動化しない。

Sample tool

file and project data

sample transfer、backup、restore は audio stream と別。permission と device write は必ず人間確認。

Analog fallback

line capture

USB input と別 interface output を DAW が同時利用できない場合は、stereo analog output を verified line inputs へ送る。

Historical note

OS 2.0 manual

古い OS 2.0 資料は current USB audio 非対応の根拠にしない。現行公式 guide と installed OS を確認する。

Verification ladder

1. documented_proposedcurrent official source と reversible design を記録。
2. partially_verifiedendpoint、DAW lane、cable の一部を read-only 確認。
3. verified_on_devicecurrent device、OS、route、cable、audible output を人間が確認。
