# ギターと三線を一音ずつ練習する

2026-10-28 初版。既存Musicの [一音ずつ](../practice/index.html) をListenから開く。
独自の短い練習フレーズで、ギターのTAB譜と三線の工工四を切り替える。
Simply Guitar本体・教材・曲集の移植ではなく、単音の正解を待つ小さな練習アプリ。

「マイクで始める」で音程を照合し、約130 ms安定すれば次へ進む。標準の許容幅は45 cent。
同じ音が続く場合は余韻だけで進めず、65 ms以上の静音または減衰後の新たなアタックを待つ。
「画面で試す」はマイク不要の別モードで、正しい音のボタンを押すと進む。
お手本は小さな加算合成音。録音・音源ファイルは追加しない。

- ギター：標準調弦、開放弦／1弦の0・1・3フレット／1・2弦の往復。和音判定は未対応。
- 三線：本調子、合・四・工／勘所の往復／短いフレーズ。工工四は縦に4音、列は右から左。
  基準をA・B♭・B・C・Dへ移調できる。尺の高低・装飾奏法・歌は初版に含めない。
- 譜面の任意位置から再開、開始・終了音を指定した繰り返し、3段階のお手本速度、感度変更。
- 設定のみlocalStorageへ保存。マイク音声を録音・永続保存・ネット送信しない。
- 停止／楽器・調弦・練習・範囲の変更／背景移動で、入力track・タイマー・合成音・AudioContextを破棄。
  マイク許可待ちの取消後に届いたstreamも停止する。

## PWA

`practice/manifest.webmanifest`、`practice/sw.js`を使用。SW scopeは`practice/`内。
`music-practice-v1`に自分の画面・モジュール・アイコンだけを保存する。
既存rootの`hazama-fm-v442`と他のアプリcacheを削除・更新しない。
HTTPSまたはlocalhostでマイク利用可。SWの有効化後に「オフライン準備OK」を表示する。
初回の準備には通信が必要。オフライン再読み込みはブラウザで確認し、実iPhoneは別途確認する。

## 検証と残る確認

`node scripts/check-practice.mjs`で44.1/48 kHzの独立した単音・倍音信号、無音、雑音、
オクターブ違い、同音連打、範囲、移調、PWAの対象ファイルを確認する。
ブラウザでは画面操作、合成のマイクstream経由の判定と停止、許可拒否、オフライン、スマホ幅を確認する。
初版のChrome確認で上記の16項目が通過。390 px幅で横にはみ出さず、停止後の入力track終了とAudioContext閉鎖も確認。
合成テストの成功を実楽器・実iPhoneの精度合格とはしない。弦・指の特定、
雑音下の判定、三線の立ち上がり／余韻は実物で継続調整する。
