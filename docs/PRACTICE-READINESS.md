2026-11-06。v31は販売前の改善版。販売開始や実楽器での精度合格を意味しない。

公開確認でCloudflareのindex.html転送が再表示を妨げる問題を検出し、公開版を一度v30へ戻した。
修正版は保存するHTMLの転送情報を除き、同じv31画面を変更せずに再表示できるようにする。
実際のHTTP転送を含むブラウザ試験と、既存cacheの修復・オフライン表示を確認する。

まず、初心者が自分で調弦し、短く反復して、1曲分の練習を終えられる体験を整える。
「1曲練習」から、ギターはきらきら星のかんたん伴奏、三線はてぃんさぐぬ花の1節を選ぶ。
既存の内蔵教材・出所表示・歌詞を使い、新しい音源や歌詞は追加しない。

| 確認すること | v31の状態 |
|---|---|
| 調弦→短い反復→通し練習 | 実装済み。マイク・ガイドは本人が開始する |
| 楽器別の続きと個人の歌詞 | 端末保存。アカウント間・端末間の同期はない |
| 三線の調弦 | 本調子が必要。選んだ高さは保持。別の調弦のまま次へ進めない |
| 通し練習 | ギターはきらきら星、三線は前後奏を含む1節63音。短い反復を解除して全体へ進む |
| 終了表示 | 本人が「今日の練習を終える」を押す。演奏技術の合格や歌唱採点とは扱わない |
| 更新時の整合性 | 旧HTMLと新moduleの混在を起動前に検出。導入済みの画面一式を使い、新版は待機する |
| 練習中の更新 | 区切りで明示更新。別タブは強制再読込せず、旧版用cacheを保持 |
| 実iPad・iPhoneでの音判定 | 未確認。合成信号の回帰試験と区別する |
| 初心者が説明なしで進められるか | 実際の初心者による試用は未実施 |
| 好きな曲の教材精度 | ギターは確認済み2曲・推定9曲。三線の多くは外部教材動画を使う |
| 有料提供 | 教材の提供条件、販売方法、購入後サポート、支払意思の確認が残る |

実機では、普通の強さで弾いた時の取りこぼし、間違った音で進む頻度、余韻の二重判定、
歌声や動画の音の混入、画面回転、マイク許可の拒否と復帰を確認する。
本人の私的な歌詞や録音を収集せず、端末・楽器・練習箇所と起きたことを記録する。

更新処理は [MDNのService Workerの説明](https://developer.mozilla.org/en-US/docs/Web/API/Service_Worker_API/Using_Service_Workers)
と [skipWaiting](https://developer.mozilla.org/en-US/docs/Web/API/ServiceWorkerGlobalScope/skipWaiting) を参照。
公開は既存のListenと練習PWAを使用し、必須検証・最終commitと公開物の照合を維持する。
