# Okinawa Local Lyric OS

Metadata-only lyric operating system for Music Stack.

This pack does not contain finished lyrics, melodies, samples, audio, prompt
outputs, or copied motifs. It stores a writing framework: position, boundaries,
distance, vocabulary, worldview presets, prompt packets, and schema alignment.

Scene packets make the same framework useful outside lyric drafting. Music
Stack can use them as output philosophy metadata: what pressure a take is
carrying, which images are allowed to carry it, which distance keeps it honest,
and which risks would make it cheap.

## Purpose

Use this OS when Lyric Lab or a human writing session needs Okinawa-local
pressure without turning into tourism imagery, political slogans, or personal
confession for its own sake.

The operating line:

> Do not represent Okinawa, but do not run away from Okinawa.

Politics should leak through daily life: family, work, landscaping, graves,
local distance, night rooms, AI screens, risk boundaries, and the quiet fear of
the body changing. The old libido is not reenacted. Its heat is pruned into
root, duty, and cultural stewardship.

## Files

- `00-position.md` - why this belongs in Music, and what it must not store.
- `01-core-kernel.yml` - compact kernel and safety flags.
- `02-boundaries.md` - no-lyrics and no-slogan boundaries.
- `03-distance.md` - writing distance and temperature.
- `04-vocabulary.yml` - usable terms, fragile terms, avoid terms.
- `05-audience-filters.yml` - filters for listener/context safety.
- `06-worldview-presets.yml` - scene/worldview presets for Lyric Lab.
- `07-prompt-packets.md` - prompts for distillation and generation.
- `08-index-addition.md` - index snippets and Music Stack integration notes.
- `CODEX-HANDOFF.md` - durable Codex handoff for phrase-thinking rollups.
- `PHRASE-CAPTURE-PACKET.yml` - current metadata-only capture packet.
- `prompts/CODEX-PHRASE-ROLLUP.md` - prompt for converting notes into metadata.
- `scenes/` - draft Scene OS packets; no lyric bodies or audio.

Schema:
