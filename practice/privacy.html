練習アプリへ利用条件

プライバシーポリシー

2026年11月19日 · 一音ずつ（Music Stack 練習アプリ）

端末の中で行うこと

マイクの音は、この端末のブラウザ内で音程・コードの判定に使います。アプリは録音も送信もしません。マイクは開始ボタンを押してから使い、端末が許可を管理します。

練習位置、楽器・調弦・感度、手元の歌詞や読み・時刻、コード順・動画に合わせた補正、しおり、番、マイクを最後に使えた時刻などを、このブラウザのlocalStorageに保存します。アプリはこれらを外部へ送信しません。動画に合わせる時刻は、プレーヤーへ再生位置を指示するためにも使います。YouTubeには動画IDと再生操作が伝わりますが、手元の歌詞やコードの補正データそのものは渡しません。

保存する項目の例
  • 設定：music-practice-settings-v1、music-practice-mic-gain-v1
  • 練習位置：music-practice-progress-v1、はじめの曲・プレイリストの進み具合
  • 歌詞・読み・意味・行と時刻：music-practice-session-lyrics-v2:…、表示方法と動画／コード送りの選択。以前の版の歌詞も読み込みます。
  • 弾き語り：music-practice-singalong-v1、曲ごとのコード時刻の補正
  • 三線の教材：music-practice-sanshin-video-…-v1、区間・速さ・しおり・教材の選択
  • 番：music-practice-minyo-verses-v1
  • マイクの利用履歴：music-practice-mic-last-used-v1。OSの許可を代わりに保存するものではありません。
  • 動画への同意：music-practice-youtube-consent-v1。選択・ポリシーの版・選択時刻を保存します。

YouTubeとの通信

このアプリはYouTube API Services（埋め込みプレーヤー）を使います。動画を使うことに同意し、さらに「動画を読み込む」を押したときに接続します。再生枠はwww.youtube-nocookie.com、操作用スクリプトはwww.youtube.comから読み込みます。

YouTube（Google）へIPアドレス、ブラウザ・端末の情報、開いた動画や再生操作などの情報が送られ、cookieなどが使われることがあります。プライバシー強化モードでも通信や情報送信がなくなるわけではありません。動画内で広告などの第三者コンテンツが表示される場合もあります。詳しくはGoogleプライバシーポリシーとYouTube利用規約を確認してください。アプリはGoogleアカウントへのログインやアカウント情報へのアクセス権を求めません。

動画への同意を変える

アプリの「規約とプライバシー」からいつでも変更できます。「動画を使わずに続ける」を選ぶと、読み込んだ動画と動画用のマイク判定を止め、再生枠を外し、その後は動画を読み込みません。調弦・内蔵譜・手元の歌詞はそのまま使えます。見送った後でも、動画の読込ボタンで説明を開いて選び直せます。選択を保存できない端末では、開き直したときに再確認します。

そのほかの接続

自分でMIDIのURLを入れた場合は、端末からその配信元へ直接取得しに行きます。その配信元へIPアドレスなどの接続情報が伝わります。参考教材やApple Musicなどのリンクも、自分で開くとそれぞれの配信元へ接続します。

アプリの表示・更新確認・オフラインの準備では、現在使っている配信元（Cloudflare PagesまたはGitHub Pages）へ接続します。通信先は通常の接続情報を受け取り、各事業者が運用ログなどを管理する場合があります。オフライン用のアプリ・内蔵教材はブラウザのキャッシュに保存します。YouTubeの動画はオフライン用に保存しません。

利用状況の計測

アプリのコードに独自のアクセス計測は実装していません。2026年11月19日に確認した両公開先のHTMLにも、Cloudflare Web Analyticsなどの追加の計測スクリプトは見つかりませんでした。これは配信事業者の運用ログや、同意して開くYouTube側の情報収集がないという意味ではありません。

保存内容を消す・残す

手元の歌詞は曲の編集欄で削除できます。必要な歌詞は先にLRCで保存してください。ブラウザのサイトデータを消すと、練習位置・設定・同意の選択なども消えます。このアプリには個人データを送って保存するサーバーや、別端末との自動同期はありません。

表示やプライバシーについての連絡はMusicの問い合わせへ。公開の場なので、個人情報・手元の歌詞・録音は書かないでください。
