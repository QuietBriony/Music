目指すのは「音を聴く → 一部分をいじる → 元と比べる → 続きから再開する」こと。 まずはブラウザで動く構成にし、Tidalのインストールを前提にしません。

案 1 / 素材編集

素材を並べて、ひとつ動かす

パートごとの音量・ミュート・区間を目で見て操作。元音源を保ち、比較できる編集版を作る案です。

案 2 / 履歴

何を変えたか残して、再開する

元の版と変更理由を保存。閉じて開き直しても、同じ素材・区間・つまみの状態へ戻る案です。

案 3 / 接続

画面・コード・チャットで触る

同じ曲の設定を三つの入口から編集する案。既存の道具で足りない操作が具体的になってから検討します。

確認待ち — HAZAMAの試聴

HAZAMA 01/02 × 原音/AIを短く比較してから6分arcへ。

HAZAMA v401：原音／AIの4ケースと実機確認を開く

HAZAMA 4ケース quick pass（各15–30秒）

  1. 01 原音 — Still Moving（基準 / 4 stems / 約33 MiB）。
  2. 01 AI 再現（v401 authored-rest再試聴候補）。
  3. 02 原音 — Still Moving (Hard)（02固有の基準 / 4 stems / 約33 MiB）。
  4. 02 AI 再現（暫定）（02固有AIではありません。01 authored framesデータ共有。曲ID由来の微細な揺らぎは別。比較基準は02原音）。
  5. 各画面でSTARTを一度押す。準備に失敗した時は無音の`playing`へ進まず、START直下の案内へ戻ることを確認。
  6. AIの弱端末比較には phone-light を使う。
  7. v401レイヤー判定: AIで`all off`から、`drums + bass`、`drums + arp`、`drums + bass + arp`（vocal OFF）、`defaults`を各30–90秒。短音の詰まりがどの層で出るか分ける。
  8. 歌詞と演奏を切り分けるなら 01 KARAOKE / 02 KARAOKE（原音4 stems・vocal off）。
  9. 画面ロック試験: 再生中に端末をロック（画面OFF）→10秒→端末ロック解除。同じBand Roomへ戻り、継続または正常復帰を確認。サイト権限やhidden bandのunlockとは別です。
  10. 別試験: HAZAMAからTabascoを選び、📻 原音と通常paletteへ戻ることを確認。

feedback pad: `01原音 / 01AI / 02原音 / 02AI暫定 — START、keep、fix`。Band Roomのlistening noteからcontext付きでコピーできます。

6分arc → 制作へ

  • quick passが安定したら約6分。intro / arp / drive / verse / lift / mantra / break / release / outro の役割と密度が移り、同じ短い断片に張り付かないかを見る。
