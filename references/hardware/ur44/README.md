# UR44 public reference boundary

This public directory intentionally contains no current device profile,
hostname, driver snapshot, latency measurement, channel state, physical output
chain, or repo-external evidence path.

Use it only for reusable guidance:

- inspect current driver, sample rate, buffer, I/O, monitoring, and loopback
  read-only before changing anything;
- keep a normal profile and a recording profile separate;
- record dry when appropriate and keep monitor effects distinct from inserted
  recording effects;
- let the operator control power, gain, cables, volume, and ear checks;
- store actual vendor profile files and machine observations in the optional
  private operator overlay;
- never infer current settings from an old public document.

The former exact snapshot was copied to the private source of truth before its
removal from the current public tree. It may still exist in Git history; a
history purge is a separate destructive task requiring explicit approval.

Official documentation (linked, not committed as a PDF):

<https://download.steinberg.net/downloads_hardware/UR44/UR44_documentation/UR44_OperationManual_en.pdf>
